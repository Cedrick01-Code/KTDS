# KTDS

Kageyo TSS Discipline System is a mobile-first Flutter application for school
discipline workflows.

## Run locally

Install Flutter, then run:

```powershell
flutter pub get
flutter test
flutter run
```

The current foundation includes the Material 3 brand theme, KTSS logo asset,
mobile login flow, responsive admin dashboard shell, bottom navigation, and a
widget smoke test. Backend authentication and role permissions must remain
server-controlled as the API is added.
